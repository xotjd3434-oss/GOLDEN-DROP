# GOLDEN DROP | 취향을 담은 한 잔

위스키의 풍미와 이야기를 소개하는 프리미엄 위스키 컬렉션 사이트입니다.  
HTML, CSS, JavaScript와 Supabase를 활용한 포트폴리오 프로젝트로, 실제 주문·결제·배송 기능은 제공하지 않습니다.

## 기술 스택

| 기술 | 사용 목적 |
| --- | --- |
| HTML5 | 시맨틱 구조, 입력 폼, 상세 모달, FAQ |
| CSS3 | Grid·Flex 레이아웃, 반응형 디자인, 전환 효과 |
| JavaScript ES Modules | 검색, 필터, 더보기, 모달, 입력값 검증 |
| Supabase JavaScript SDK v2 | 인증·데이터베이스·저장소 연결 |
| Supabase Auth | 이메일 회원가입, 로그인, 로그아웃 |
| Supabase Database / PostgreSQL | 위스키 정보 저장 및 조회 |
| Supabase RLS | 운영자 전용 등록 권한 관리 |
| Supabase Storage | 위스키 이미지 저장 |
| localStorage | 브라우저에 찜·장바구니 저장 |
| VS Code / Live Server | 코드 편집 및 로컬 실행 |

## Supabase 설정

### 1. 위스키 테이블

**`public."GOLDEN DROP"`** — 위스키 정보

| 컬럼 | 타입 | 설명 |
| --- | --- | --- |
| id | int8 (PK) | 위스키 ID, 자동 생성 설정 필요 |
| title | text | 위스키 이름 |
| brand | text | 브랜드 |
| category | text | 위스키 분류 |
| description | text | 상품 설명 |
| price | int8 | 가격 (원) |
| image_url | text | 이미지 공개 URL |
| volume_ml | int8 | 용량 (ml) |
| origin | text | 원산지 |

등록 코드는 위 컬럼 이름을 기준으로 동작합니다. 기존 테이블의 실제 타입과 기본값은 Supabase에서 확인합니다.

### 2. 카테고리

등록 폼과 컬렉션 필터에서 동일한 값을 사용합니다.

- 싱글몰트 스카치
- 블렌디드 스카치
- 버번
- 싱글몰트 재패니즈
- 블렌디드 재패니즈
- 블렌디드 위스키

### 3. 이미지 저장소

| 항목 | 설정 |
| --- | --- |
| 버킷 | `GOLDEN DROP-images` |
| 공개 설정 | Public |
| 저장 경로 | `whiskies/UUID.확장자` |
| 허용 형식 | JPG / PNG / WEBP |
| 최대 용량 | 3MB |

Public 설정은 이미지 공개 조회에 사용합니다. 업로드·삭제 권한은 Storage 정책으로 별도 제한합니다.

### 4. 계정 및 운영자

회원 계정은 Supabase Auth의 `auth.users`에서 관리합니다.

`public.is_admin()` 함수는 현재 로그인한 사용자의 UID를 지정한 운영자 UID와 비교합니다. 이메일이 아닌 **Authentication → Users의 User UID**를 사용합니다.

| 사용자 | 허용 기능 |
| --- | --- |
| 비로그인 방문자 | 위스키 조회, 검색, 필터, 상세 보기 |
| 일반 회원 | 방문자 기능 및 로그인·로그아웃 |
| 운영자 | 위스키 등록 및 이미지 업로드 |

찜·장바구니는 로그인과 관계없이 현재 브라우저에 저장됩니다.

### 5. RLS 정책

| 대상 | 작업 | 허용 조건 |
| --- | --- | --- |
| 위스키 테이블 | SELECT | 방문자와 로그인 사용자 조회 |
| 위스키 테이블 | INSERT | `public.is_admin()`이 참인 사용자 |
| 이미지 저장소 | INSERT | 지정 버킷 및 운영자 확인 |
| 이미지 저장소 | SELECT | 운영자의 파일 조회·정리 |
| 이미지 저장소 | DELETE | 지정 버킷 및 운영자 확인 |

다른 INSERT 또는 ALL 정책이 일반 사용자에게 쓰기를 허용하면 운영자 전용 제한이 적용되지 않을 수 있으므로 기존 정책을 함께 확인합니다.

### 6. 설정 순서

1. 운영자로 사용할 사이트 계정을 생성합니다.
2. Authentication → Users에서 해당 계정의 UID를 복사합니다.
3. `supabase-admin.sql`의 `REPLACE_WITH_ADMIN_UID`를 실제 UID로 변경합니다.
4. SQL Editor에서 스크립트를 실행합니다.
5. `GOLDEN DROP-images` 버킷의 Public 설정을 확인합니다.
6. 운영자 계정으로 사이트에 로그인해 등록을 테스트합니다.
7. 일반 회원·로그아웃 상태에서는 등록이 차단되는지 확인합니다.

### 7. 찜·장바구니 저장

별도의 주문 테이블은 사용하지 않습니다.

| 저장 키 | 내용 |
| --- | --- |
| `goldenDropWishlist` | 찜한 위스키 목록 |
| `goldenDropCart` | 장바구니 제품 및 수량 |

브라우저 데이터를 삭제하면 저장한 정보가 사라질 수 있습니다. 계정 간 분리와 다른 기기 동기화는 제공하지 않습니다.

## 실행 방법

1. 프로젝트 폴더를 VS Code에서 엽니다.
2. `js/config.js`의 Supabase URL과 공개 Key를 확인합니다.
3. Live Server로 `index.html`을 실행합니다.

ES Modules를 사용하므로 HTML 파일을 직접 더블클릭하는 `file://` 방식 대신 HTTP 환경에서 실행합니다.

프런트엔드에는 공개용 publishable key만 사용하며, `service_role` 또는 secret key를 넣지 않습니다.

## 참고 사항

- 실제 판매·주문·결제·배송 서비스가 아닙니다.
- 표시된 가격은 참고 정보입니다.
- 제품 등록은 운영자 전용입니다.
- 현재 관리 화면은 신규 등록을 제공하며 제품 수정·삭제 UI는 포함하지 않습니다.
- 기존 수업 주석은 보존되어 일부 작품 관련 표현이 남아 있습니다.
- 이미지 정리에 실패하면 Storage에서 남은 파일을 확인해야 합니다.

## Storage

위스키 이미지는 Supabase Storage의 `GOLDEN DROP-images` 버킷에 저장합니다.

- Public 버킷으로 제품 이미지 공개 조회
- `whiskies/UUID.확장자` 경로로 파일명 중복 방지
- JPG / PNG / WEBP 형식, 최대 3MB
- 업로드 전 이미지 미리보기 제공
- DB 저장 실패 시 업로드된 이미지 삭제 시도

파일 형식과 용량은 현재 JavaScript에서 검사합니다. 저장소 측 제한 설정도 별도 확인이 필요합니다.

## 보안 (RLS)

위스키 조회와 등록 권한을 분리합니다.

| 대상 | 작업 | 권한 |
| --- | --- | --- |
| 위스키 테이블 | SELECT | 누구나 조회 |
| 위스키 테이블 | INSERT | 운영자만 등록 |
| 이미지 저장소 | INSERT | 운영자만 업로드 |
| 이미지 저장소 | SELECT / DELETE | 운영자 파일 조회 및 정리 |

- `public.is_admin()` 함수로 로그인 사용자의 UID와 운영자 UID 비교
- 운영자에게만 관리 메뉴와 등록 폼 표시
- 실제 데이터 접근은 Supabase RLS 정책으로 제한
- 프런트엔드에는 공개용 publishable key 사용
- `service_role` 및 secret key는 프런트엔드에 사용하지 않음

운영자 전용 정책 외에 쓰기를 허용하는 기존 정책이 남아 있는지 확인해야 합니다. 운영자·일반 회원·비로그인 상태별 실제 권한 테스트가 필요합니다.
